# GhostCorp Experiment Protocol

Use this template for every research claim, novel capability, or performance improvement.

## Experiment record

- Experiment ID:
- Title:
- Owner / responsible agent:
- Date opened / last updated:
- Research program:
- Status: IDEA | HYPOTHESIS | PROTOTYPE | RUNNING | PRELIMINARY | REPLICATED | VALIDATED | REJECTED | ARCHIVED
- Related code commit / branch:
- Data and license:
- Hardware and model versions:
- Resource budget: $0 by default; specify CPU/GPU, memory, storage, runtime and API quota.

## Research question
What precise question is being answered?

## Hypothesis
State a falsifiable prediction. Include the conditions under which it would be wrong.

## Prior art
List relevant papers, projects, patents, and competing approaches. Explain the difference between this work and the closest prior art. Do not claim global novelty without a serious prior-art review.

## Method
- Baseline(s):
- Treatment / proposed method:
- Dataset and sampling:
- Controls:
- Number of runs / random seeds:
- Reproduction instructions:

## Metrics
Choose task-specific measurable outcomes. Examples: exact-match or task success, human-rated quality with rubric, latency, tokens, energy, memory, recovery time, cost, failure rate, calibration, privacy leakage, and security test outcomes.

## Results
Report all runs, including failures and inconclusive outcomes. Include raw machine-readable results where possible. Do not cherry-pick.

## Analysis
Separate observations from interpretation. Note confounders, uncertainty, sample size, and limitations.

## Safety and release review
- Privacy and data permissions:
- Security and abuse cases:
- Model/data/software license:
- Human impact and accessibility:
- Reversibility and rollback:
- Public-release decision and rationale:

## Conclusion
Use one of: supported, partially supported, not supported, inconclusive. State what the result does and does not establish.

## Educational derivative
- What can a learner understand from this?
- What safe demo can be published?
- What prerequisites are needed?
- Can the result be independently reproduced?
